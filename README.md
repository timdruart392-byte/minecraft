# BlockWorld 3D

Petit jeu original de construction en blocs, jouable directement dans un navigateur moderne.

## Jouer
Ouvre **index.html** dans un navigateur avec une connexion Internet (Three.js est chargé depuis jsDelivr), ou active GitHub Pages dans **Settings → Pages** pour publier le jeu.

## Commandes
- **ZQSD / WASD** : déplacement
- **Espace** : sauter
- **Maj** : courir
- **Clic gauche** : casser un bloc
- **Clic droit** : poser un bloc
- **1 à 5** : choisir le type de bloc
- **Échap** : libérer la souris

Le projet est une création indépendante et n'utilise pas les ressources propriétaires de Minecraft.
